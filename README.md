### 1. Giới thiệu bài tập

Bài tập cá nhân Buổi 2 tiếp tục phát triển website từ Buổi 1, tập trung thực hành các kiến thức HTML5 và CSS3 nhằm cải thiện cấu trúc, bố cục và giao diện website.

Dự án được thực hiện trên website **GRIMM – Streetwear UI Concept**, một giao diện website thương mại điện tử thời trang Streetwear.

### 2. Website tham khảo và khu vực đã cải tiến

- **Tên website:** GRIMM – Streetwear UI Concept
- **Website tham khảo:** [Điền đường dẫn website tham khảo ban đầu]
- **Khu vực thực hiện cải tiến:**
  - Cấu trúc HTML của các khu vực trên website.
  - Khu vực Hero giới thiệu thương hiệu.
  - Danh sách và thẻ sản phẩm.
  - Bố cục hiển thị sản phẩm.
  - Hiệu ứng tương tác trên các nút bấm.

### 3. Những kỹ thuật HTML5/CSS3 đã thực hành

**HTML5:**
- Sử dụng các thẻ ngữ nghĩa như `header`, `nav`, `main`, `section`, `article`, `footer`.
- Sử dụng thẻ `img` kết hợp thuộc tính `alt` để mô tả hình ảnh.
- Sử dụng các phần tử `button` và `a` cho những thành phần tương tác.

**CSS3:**
- Sử dụng CSS Selector để định dạng các phần tử HTML.
- Thực hành Box Model với `margin`, `padding`, `border`.
- Sử dụng Flexbox để bố trí khu vực Hero.
- Sử dụng CSS Grid để sắp xếp danh sách sản phẩm.
- Điều chỉnh hình ảnh bằng `aspect-ratio` và `object-fit: cover`.
- Sử dụng Media Queries để điều chỉnh giao diện theo kích thước màn hình.
- Bổ sung hiệu ứng `:hover`, `:active`, `:focus-visible` và `transition`.

### 4. Hướng dẫn chạy website

1. Clone hoặc tải repository về máy tính.
2. Mở thư mục dự án.
3. Mở tệp `index.html` bằng trình duyệt Google Chrome.
4. Quan sát giao diện website.
5. Khi chỉnh sửa giao diện, mở tệp `style.css`, lưu thay đổi và tải lại trang để kiểm tra kết quả.

### 5. Những thay đổi đã thực hiện

- Bổ sung và hoàn thiện cấu trúc HTML5 cho các khu vực giao diện.
- Sử dụng CSS Selector và Box Model để định dạng thẻ sản phẩm.
- Chuyển bố cục khu vực Hero sang sử dụng Flexbox.
- Sử dụng CSS Grid để sắp xếp danh sách sản phẩm thành các cột.
- Điều chỉnh khoảng cách và tỷ lệ hiển thị hình ảnh sản phẩm.
- Bổ sung hiệu ứng Hover và Focus-visible cho nút thêm vào giỏ hàng.
- Kiểm tra giao diện và điều chỉnh khoảng cách dòng tiêu đề Hero bằng thuộc tính `line-height`.
